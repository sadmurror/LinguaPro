# Обучающая информационная онлайн-система в области иностранных языков для образовательного центра «LinguaPro»

Система рассматривается как веб-приложение для размещения учебных материалов по английскому, немецкому и китайскому языкам, организации прохождения курсов, контроля посещаемости и успеваемости, а также взаимодействия участников образовательного процесса.

- Для обучающегося система становится личным учебным кабинетом: он видит своё расписание, получает напоминания, скачивает материалы, сдаёт задания и отслеживает прогресс. 
- Для преподавателя система является рабочим инструментом: он отмечает посещаемость в пару кликов, просматривает успеваемость группы, выставляет домашние задания. 
- Для администратора система автоматизирует рутинные задачи: заявки регистрируются автоматически, расписание строится без конфликтов, счета генерируются по факту посещений. 
- Для директора система предоставляет дашборды с ключевыми показателями. 

Проблема, которую решает система, заключается в том, что образовательный процесс в центре «LinguaPro» в настоящее время распределён между несколькими несвязанными инструментами. Учебные материалы хранятся в облачных папках и мессенджерах, расписание составляется вручную в Excel, посещаемость фиксируется в бумажных журналах, счета выставляются на основе этих журналов с задержкой до недели, а финансы ведутся в 1С без прямой связи с фактическими занятиями. При таком подходе возникают конфликты расписания, теряются заявки, задерживается выставление счетов, а руководство не имеет оперативной отчётности.

С этой проблемой сталкиваются все участники. Обучающиеся (клиенты) испытывают неудобства: нет единого личного кабинета, нет автоматических напоминаний о занятиях, сложно отслеживать свой прогресс и домашние задания. Преподаватели вынуждены вручную отмечать посещаемость в тетрадях, затем дублировать данные в Excel, а также тратить время на напоминания ученикам. Администраторы тратят до 15 часов в неделю на составление расписания, разрешение конфликтов, перенос данных из бумажных журналов в учётную систему. Директор не может оперативно получить отчёты по загрузке преподавателей, финансовым показателям и удержанию клиентов.
