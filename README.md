# LinguaPro

**Назначение системы:**  Автоматизация образовательного процесса в языковом центре. Система охватывает полный цикл: от первичной записи на пробное занятие до выдачи сертификата, ведения очного расписания, учёта посещаемости и постоплаты счетов.

## Пользователи системы
Гость, ученик, преподаватель, администратор, методист, бухгалтер, директор, системный администратор.

## Основные возможности
1. Просмотр гостем каталога курсов и расписания без регистрации.
2. Запись на курс с мгновенным доступом к расписанию и электронным договором (без предоплаты).
3. Автоматическое формирование расписания с проверкой конфликтов (преподаватели и аудитории).
4. Электронный журнал посещаемости (отметки «присутствовал», «опоздал», «отсутствовал»).
5. Постоплатная система: автоматический расчёт начислений по итогам периода на основе фактической посещаемости и оценок ученика (с интеграцией 1С).
6. Выдача и проверка домашних заданий, просмотр успеваемости и прогресса.
7. Формирование аналитических дашбордов для директора и финансовой отчётности.
